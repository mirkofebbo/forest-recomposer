# Forest Video Recomposer  
![version](https://img.shields.io/badge/version-0.0.1-blue)
[![MIT License](https://img.shields.io/badge/License-MIT-green.svg)](https://choosealicense.com/licenses/mit/)


1. Search or paste YouTube URLs 
2. Save to edit list 
3. mark interesting moments (time ranges) START - RANGE
4. tag them (e.g. “GREEN”, “HUMAN”, “WATER”, “ROAD”, "COMMUNITY”) 
5. Save to save list 
6. hit “Recompose” .

## UI 
### Left 
Add button -> change center window for a search modal
Edit section, list of youtube clip selected

### Center 
timecodes editor (start/end, tag, notes)
or search modal 
or recomposer modal 

### Right
Edited videos with timecodes recomposition

## Installation

Getting started is a simple as cloning the repository

```
git clone git@github.com:mirkofebbo/forest-recomposer.git
```

Changing into the new directory

```
cd forest-recomposer
```

Installing dependencies

```
npm install
```


Congrats! You're ready to starting working on that new project!

If you'd rather run the commands above in one go, check out the command below:

```
git clone git@github.com:mirkofebbo/forest-recomposer.git
cd forest-recomposer
npm install
```
## Execution / Usage

To run **Forest Video Recomposer**, fire up a terminal window and run the following command:

```sh
 npm run dev 
```

By enabling host mode, the server will host the website online and can be access using other computer/mobile via the IP address
```sh
 npm run dev -- --host
```
